\chapter{Methodology}\label{chap:methodology}


\section{Dataset}
The experiments use the FIFA World Cup 98 dataset, which logs every HTTP request made to the official 1998 World Cup website. We aggregated the logs into requests per minute. The main reason for this choice is comparability: Dogani and Khunjush~\cite{dogani2024} use the same dataset, so our results can be set directly against theirs. They report 88 days starting on 30 April. Logging on that first day only began at 23:30, however, so it contains just 30 minutes and 325 requests. We dropped it, leaving a trace from 1 May to 26 July 1998: 87 days, or 125,280 minutes.
