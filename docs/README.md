# docs

This folder holds the written documents of the repository. Start with `decisions.md`: it lists every choice of the reproduction and every result that differs from Dogani & Khunjush (2024).

- `decisions.md`: the decisions log. The entries are numbered by step (1.x to 4B.x), followed by the findings 4.1 to 4.18.
- `demo_live.md`: how to run the live demo of step 4B, in about 5 minutes or in full.
- `demo.md`: earlier part: a 10 to 15 minute demo of the CPU controllers.
- `concepts.md`: earlier part: plain-language notes on the ideas behind the CPU controllers.
