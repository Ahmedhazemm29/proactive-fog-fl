# figures

This folder belongs to the earlier part of the thesis. It holds the PDF figures of the first reactive and proactive runs, on 2 October, with a sine load whose waves came about 20 s apart. `analysis/compare_runs.py` made them, and their tables are in `results/comparison.md`.

- `demand_usage_<controller>_<run>.pdf`: CPU demand and CPU use of each worker, for runs 1 to 3 of each controller.
- `limits_<controller>_<run>.pdf`: CPU limits of each worker, for the same runs.
